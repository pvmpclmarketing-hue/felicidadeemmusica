# Canção Única

Checkout de música personalizada pronto para ser separado entre Vercel, Supabase e Railway.

- `app/`: site público Next.js, publicado na Vercel.
- `supabase/`: banco PostgreSQL e Edge Functions para Pix/Asaas.
- `railway-worker/`: fila de geração da música com a API Kie.

Leia [DEPLOY.md](./DEPLOY.md) antes de publicar. Nenhuma chave de pagamento, música ou WhatsApp deve ser colocada no frontend.
